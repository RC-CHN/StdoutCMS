## Reading and writing

- The homepage loads three article summaries per page. The article directory
  loads when first shown and stays available while navigating between posts.
  Existing clients can still request the full post list. API clients can select
  summaries with `view=summary`.
- The footer, article view, and editor share one site information request.
  The backend retrieves the article and project counts in one database round trip.
- Article and About editors pause Markdown rendering while the preview is
  hidden. Reopening the preview shows the latest text and preserves its scroll
  position. Desktop split view continues to update as you type.
- Leaving an editor or unmounting a chat widget cancels its pending AI request.
  Completed questions and replies are saved together in Redis.

## Upgrade

- Preserve ordinary articles with the slug `about` after the standalone About
  page has been migrated.
- The backend applies migration `003_image_cleanup.sql` at startup. It queues
  images removed from server-saved content and checks remaining references
  before deleting an object. Uploads that exist only in local editor drafts
  stay in storage.
