This release improves reading, mobile administration, and writing recovery while
preserving the terminal-inspired design.

## Reading and navigation

- Keep pagination in the URL and restore the reading position when returning
  from an article. Article contents links navigate without reloading the post.
- Add article contents, clearer titles and metadata, and a narrower reading
  column with improved typography.
- Support mobile sharing, accessible QR dialogs, and on-demand loading of the
  sharing image exporter.
- Remove the artificial page-transition delay, compact the mobile header, and
  respect reduced-motion preferences.
- Distinguish loading, empty, and failed requests, with retry actions.
- Extend Markdown support with GFM tables, task lists, deeper nested lists,
  and deduplicated heading anchors.

## Writing and administration

- Keep local backups separate for each article, offer explicit recovery, and
  preserve form contents after saving.
- Separate saving, publishing, and unpublishing. Saving an already published
  article preserves its publication state.
- Share upload state between toolbar selection and pasted images. Failed
  uploads can be retried or removed; incomplete uploads block saving.
- Adapt admin lists and editor panes to narrow screens, with mobile
  edit/preview tabs and persistent save controls.
- Preserve About content when loading fails and allow retrying the request.

## Backend fixes

- Preserve images referenced by the About page during orphan cleanup.
- Return a service error if login session storage fails, rather than reporting
  a successful login.
- Return complete public post metadata and correct missing-resource responses;
  validate post slugs consistently.

## Release process

- Centralize the application version in the root `VERSION` file.
- Require new release tags to point to `chore: release vX.Y.Z` commits that
  change only `VERSION`.
- Validate release metadata and run frontend, backend, and release-tooling
  checks before publishing images and the GitHub Release.

Container images:

- `ghcr.io/rc-chn/stdoutcms/backend:0.4.0`
- `ghcr.io/rc-chn/stdoutcms/frontend:0.4.0`

Standalone backend Docker builds now use `docker build -f backend/Dockerfile .`
from the repository root. Existing Docker Compose commands continue to work.
